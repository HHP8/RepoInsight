# Support

Use the issue templates for reproducible bugs and focused feature requests. Include the RepoInsight version, operating system, Python version, command shape, exit code, and redacted diagnostics. Do not attach private repositories, access tokens, credentials, or unredacted reports.

Security reports belong in the private process described by [SECURITY.md](SECURITY.md). General Python, Git, CI, or repository-design consulting is outside the project support scope.
