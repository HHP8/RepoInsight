# Order total example

## Purpose

This tiny synthetic Python project adds item prices and prints a total. It is a
teaching example for a RepoInsight walkthrough, not production software.

## Installation

Use Python 3.11 or newer. No third-party dependencies are required.

## Usage

From this directory:

```console
python totals.py
```

Expected output:

```text
Order total: 20.00
```

## Development and testing

The sample deliberately has no automated test suite. RepoInsight performs static
analysis; its report does not run this program or verify its behavior.
